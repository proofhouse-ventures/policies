# Privacy Policy — Diagrams as Code for Confluence

**Vendor:** Proofhouse Ventures Pte. Ltd. ("Proofhouse Ventures")
**App:** Diagrams as Code for Confluence (Atlassian Marketplace)
**Effective date:** 22 November 2026
**Contact:** wrenshelf@gmail.com

## Summary

Diagrams as Code for Confluence renders Mermaid, Graphviz and PlantUML diagrams from source text stored in Confluence pages. The app is built to collect nothing: it has no analytics, no tracking, no external network connections, and no sub-processors.

## What data the app handles

- **Diagram source in pages.** The diagram source a user types into the macro is stored in that Confluence page's macro configuration, inside the customer's own Confluence site. Proofhouse Ventures cannot access it.
- **Pro diagram library.** If a site uses the paid Pro library feature, saved entries (diagram source, a title, and a theme choice) are stored in Atlassian Forge hosted storage, under the installing site and keyed by Confluence space. Entries remain until a user deletes them or the app is uninstalled.

## Personal data

The app does **not** collect, store, or process end-user personal data. It makes no Confluence or Jira API calls — its only permission is `storage:app` (Forge hosted storage for the Pro library). It does not read page content, user profiles, or any other site data through an API.

## Data transfers and sub-processors

None. All rendering happens in the reader's browser from libraries bundled with the app. The app declares no external network permissions and connects to no external service. There are no sub-processors.

## Retention and deletion

Library entries persist until deleted by a user of the site or until the app is uninstalled. Diagram source stored in pages is governed by the site's own Confluence retention and deletion controls.
